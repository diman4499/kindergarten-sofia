# Заявки на посещение Star Kids

Форма на `kontakti.html#visit` → Google Apps Script → закрытая Google Таблица.
Telegram подключается дополнительно: таблица сохраняет заявку первой, затем отправляется уведомление.

## Подключение

1. В Google аккаунте владельца сада создайте **закрытую** таблицу «Star Kids — посещения». Не публикуйте её и не включайте доступ по ссылке.
2. Откройте Расширения → Apps Script и вставьте содержимое `Code.gs`.
3. В Настройки проекта → Свойства скрипта добавьте `SPREADSHEET_ID`: часть URL таблицы между `/d/` и `/edit`.
4. Для уведомлений создайте отдельного бота через @BotFather, начните с ним диалог или добавьте в закрытую группу администрации. В свойствах скрипта добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Не отправляйте токен в GitHub, issues или исходники сайта. Для одной таблицы Telegram не обязателен.
5. Развернуть → Новое развертывание → Веб-приложение. Выполнять от имени владельца; доступ — «Все» (включая посетителей без Google аккаунта). Подтвердите доступ скрипта к таблицам и, при Telegram, к внешним запросам. Если организация запрещает анонимные веб-приложения, нужен другой серверный обработчик.
6. Скопируйте URL с окончанием `/exec` в `window.VISIT_FORM_ENDPOINT` в `assets/visit-form-config.js`. Это публичный адрес обработчика, не секрет. `/dev` использовать нельзя.
7. После изменения `Code.gs` обновляйте версию развертывания. Объедините изменения сайта в `main`, дождитесь GitHub Pages.

До настройки URL кнопка отправки отключена, видны телефон и email. Форма не имитирует успешную отправку.

## Проверка перед запуском

- Откройте опубликованную страницу в приватном окне без входа в Google. Заполните тестовыми данными, выберите базу и согласие. Должно появиться подтверждение, в листе «Посещения» — одна строка, в Telegram — одно сообщение (если подключён).
- Проверьте на телефоне. Имя, телефон, возраст, база и согласие обязательны. Время и заметки — нет.
- При повторе **того же** запроса после сетевой ошибки используется прежний ID: строка и уведомление не дублируются. Изменение полей создаёт новую заявку. Повторные заявки с одного телефона ограничены одной в минуту.
- Отключите сеть: подтверждения быть не должно, данные остаются в полях. Если запись успела сохраниться до обрыва, повторите без изменений — сервер подтвердит тот же ID.
- При неверных настройках Telegram заявка остаётся в таблице; колонка Telegram показывает ошибку. Автоматической повторной отправки Telegram нет, проверяйте таблицу регулярно.
- Проверяйте именно реальное анонимное развертывание: локальные тесты не подтверждают права Google, редиректы/CORS или доставку Telegram. Не заменяйте fetch на `mode: 'no-cors'`: непрозрачный ответ не подтверждает сохранение.

## Обслуживание

В таблице есть дата, родитель, телефон, возраст, база, время, заметки, согласие, статус заявки и Telegram. Администратор меняет «Нова» на «Свързахме се», «Потвърдено» или «Приключено». При ошибке Telegram основным списком остаётся таблица.

Сейчас на сайте указан только адрес Овча купел, Монтевидео 4; другие базы не выдуманы. При добавлении базы синхронно обновите HTML и `VISIT_LOCATIONS` в скрипте. Цвета формы соответствуют существующему сайту; состав полей — примеру.

Публичный обработчик проверяет поля, UUID, согласие, скрытую ловушку и ограничивает частоту по телефону; это базовая защита, не полноценная CAPTCHA и не защита от целевого потока запросов. Следите за квотами Apps Script. Не храните данные родителей в публичном репозитории. Доступ к таблице и Telegram выдавайте только ответственным сотрудникам; определите срок удаления заявок и текст политики сада перед запуском.

## Локальные проверки

`node --test tests/visit-form.test.cjs`

Браузерные проверки (нужны пакет Playwright и установленный Chromium): `node tests/visit-form-browser.cjs`. Включают мобильную/настольную ширину, валидацию, ошибку сети и повтор с прежним ID. Реальный Google/Telegram ими не вызывается.

Документация: [Apps Script Web Apps](https://developers.google.com/apps-script/guides/web), [Content Service и редиректы](https://developers.google.com/apps-script/guides/content), [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage).
